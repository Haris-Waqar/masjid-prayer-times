# Design direction

## Tokens

- Minaret forest `#103e39`: primary field and trust
- Courtyard jade `#2d766d`: actions and current state
- Brass lamp `#d1a95f`: one warm, visible accent
- Morning paper `#f6f8f3`: low-glare background
- Ink `#14201e`: text
- Stone line `#dbe2da`: structure

Charter/Iowan Old Style gives prayer names a quiet, civic character. Avenir Next
or Segoe UI keeps controls highly legible without downloading web fonts.

## Layout

Mobile puts the next jamaat first, then the five-row timetable and install action.
Desktop pairs a tall mihrab-shaped next-prayer field with the timetable. Content
is left aligned except for the centered next-prayer focus.

## Review

The memorable element is the architectural arch around the next prayer. Other
surfaces remain plain and functional. Decorative mosque photography and repeated
card grids were removed because they compete with the time—the one fact a person
must be able to read immediately.
