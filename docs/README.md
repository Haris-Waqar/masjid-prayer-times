# Engineering handbook

These guides define the repository's working agreements. Changes should follow all applicable guides; reviewers should treat violations as defects rather than optional style preferences.

| Guide                                               | Use it when                                                            |
| --------------------------------------------------- | ---------------------------------------------------------------------- |
| [Coding standards](coding-standards.md)             | Writing or reviewing application, database, or test code               |
| [Project structure](project-structure.md)           | Adding routes, components, data access, migrations, or tests           |
| [UI, UX, and accessibility](ui-ux-accessibility.md) | Changing any user-visible interface or interaction                     |
| [Error handling](error-handling.md)                 | Adding failure paths, logging, retries, or compensation                |
| [API integration](api-integration.md)               | Creating or consuming Route Handlers or privileged Supabase operations |

The maintainers of this repository own the handbook. Update the relevant guide in the same change whenever a convention or architectural boundary changes. Product requirements remain in `SPEC.md`; visual direction remains in `DESIGN.md`.
